# Repository guidance

- Keep this a personal portfolio for Abivan. Exclude the EPL predictor, Spike Fit, and LeBron/CR7 fan pages from the showcased projects.
- Keep bios, project descriptions, awards, and dates factual. Do not infer claims that are not supported by Abivan or the project sources.
- `src/data/projects.json` is generated by `scripts/sync-projects.mjs`. Correct GitHub-backed facts at their source; keep offline projects and curated recognitions in the script. Standalone events live in `src/data/events.json`.
- Featured projects and shared project links are defined in `src/lib/portfolio.ts`. Preserve the separate home, projects, and toolkit pages when changing shared behavior.
- Keep interfaces responsive, keyboard accessible, and respectful of reduced-motion preferences.
- Before finishing code changes, run `npm run build` and `npm run lint`.
